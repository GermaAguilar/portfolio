# Portafolio de Germain Aguilar

Código de mi portafolio personal: una página estática que resume mi trayectoria (10 años como contador y 2 como desarrollador), las herramientas con las que trabajo y mis proyectos.

## Cómo verlo

Es una sola página sin paso de compilación. Clona el repositorio y abre `index.html` en el navegador.

```bash
git clone https://github.com/GermaAguilar/portfolio.git
```

Necesita conexión a internet, porque los estilos y los íconos se cargan desde un CDN.

## Con qué está hecho

- **HTML** y **Tailwind CSS** (por CDN), con estilos propios para el efecto de vidrio.
- **Font Awesome** para los íconos.
- **JavaScript** sin librerías para el menú móvil, el desplazamiento suave y el formulario.

El formulario de contacto no usa servidor: abre la aplicación de correo del visitante con el mensaje ya escrito.

## Proyectos que muestra

- **Alcuadre:** aplicación web de conciliación bancaria (Python, Dash). Código privado.
- **[Renta Comercial y Fiscal](https://github.com/GermaAguilar/RCF):** macro de Excel que genera los reportes fiscales a partir del balance de comprobación (VBA).
- **[Recordatorio de Pagos](https://github.com/GermaAguilar/payment_reminder):** aplicación de escritorio para controlar pagos pendientes (Python, Tkinter).
